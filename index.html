01 — THE PROJECTFROM RAW RECORDS TO REAL INSIGHT

Sport is the spectacle.
Data is the lens.

This Skill Bridge project explores Olympic records through a set of interactive visualizations. It turns a large dataset into a clearer view of how athletes compete, how medals are distributed, and how participation changes across sports and time.

Use the dashboard to investigate the charts yourself, then switch to the data story for an explanatory view of the findings.
