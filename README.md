# Olympics Atlas — Skill Bridge Project

A responsive, premium dark-theme website presenting an Olympics data analytics project. The page includes a project overview, key insight cards, and embedded Tableau dashboard/story views.

## Tableau links
- Dashboard: https://public.tableau.com/app/profile/sudhanshu.dwivedi4562/viz/Book1_17931641802290/Dashboard1?publish=yes
- Story: https://public.tableau.com/app/profile/sudhanshu.dwivedi4562/viz/Book1_17931641802290/Story1?publish=yes

## Files
- `index.html` — content and Tableau embed
- `style.css` — layout, visual design, responsive behavior, animations
- `script.js` — Dashboard/Story switcher, mobile menu, scroll progress

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

## Publish with GitHub Pages
1. Create a public GitHub repository (e.g. `olympics-atlas`).
2. Upload these files directly into the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select branch `main` and folder `/(root)`, then click **Save**.
5. Wait for GitHub Pages to publish your site; the public URL appears in the Pages section.

## Notes
- The Tableau workbook must remain published and accessible for embeds to load.
- If a browser/network blocks the embed, use **Open full view** to visit Tableau Public.
- Insight cards contain summary/illustrative graphics. Use the embedded Tableau workbook for interactive exploration and exact values.
